Differential protein abundance from a Proteome Discoverer export

Load the Proteins table you exported from Proteome Discoverer. LFQ Explorer filters it, log2-transforms the normalized abundances, and compares every pair of groups, giving you a PCA, clustered heatmaps and volcano plots you can click through protein by protein.

The file needs an Accession column and per-sample abundance columns named like Abundances (Normalized): F3: Sample. Columns such as Master, Contaminant, Protein FDR Confidence: Combined, # Unique Peptides, Gene Symbol and Description are used when present.
